








#### 载荷
无人机上除了自身飞行必须的部件之外，额外带上天干活的设备。

|    载荷类型     |    干什么用    |   对应你以后处理的数据    |
| :---------: | :--------: | :-------------: |
|   相机（可见光）   |  拍照片/正射影像  | 倾斜摄影 → 3D Tiles |
| 激光雷达（LiDAR） | 打激光测距，得到点云 |  点云 → `.pnts`   |
|  多光谱/高光谱相机  |  分析植被、水质   |       影像        |
|    热红外相机    |  测温、夜间、巡检  |       影像        |
|    气体传感器    |   检测管道泄漏   |       数值        |

#### 无人机采集数据
1.规划航线：在软件里画好飞行范围，设定重叠率（相邻照片要重叠 60%~80%，这样才能拼出完整三维）。；
2.自动飞行：无人机按航线自己飞，边飞边触发相机/雷达，隔几米拍一张。；
3.采集：拍了一堆照片（可能几千张），或者扫出一片点云，这就是「采集到的原始数据」。；
4.后处理：把照片拿去三维重建（ContextCapture、大疆智图等），算出实景三维模型——这一步产出的才是你能在 Cesium 里加载的东西。；

#### 航路
在空中**划定好的、固定的飞行通道**，像高速公路一样有：

- 固定的宽度和高度范围
- 一串**航路点**（导航点）串联起来
- 有编号（比如 A461、W37）
- 由导航设施引导，飞行器沿着它飞

航路是**基础设施**，是提前划好的"空中路网"。低空经济里会为无人机、eVTOL（电动垂直起降飞行器）划定**低空航路**。


#### 航线 flight route 
某一次飞行的具体路径。

#### 三者
- **航图** → 底图 + 各类图层叠加（空域、障碍物、起降点），类似 Cesium 里的各种图层
- **航路** → 固定的线状/带状数据，可以画成一条条"空中走廊"
- **航线** → 动态的飞行轨迹，某架无人机实时/规划的飞行路径（点连成的线，带时间）
