|          **ESLint**           |             代码错误提示              |  你项目已配 `eslint.config.mjs`，装扩展后波浪线实时提示   |

|      **Auto Rename Tag**      |       改 HTML 开始标签，自动改闭合标签       |              写 HTML 时省一半操作               |

**CesiumJS 相关**

CesiumJS 没有专用的 VS Code 扩展。但可以通过项目配置让 VS Code 识别 Cesium 的全局类型——在 `.vscode/settings.json` 中配置 `"html.customData"` 或加上 Cesium 的类型声明文件。
