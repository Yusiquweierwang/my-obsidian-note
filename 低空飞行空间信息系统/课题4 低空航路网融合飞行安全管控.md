#### 低空安全风险预警
**接口 1 的输入**（你发给系统的东西——无人机实时状态）：

```json
{"uavId":"UAV001", "uavType":"VTOL", "flightPlanId":"PLAN001",
 "longitude":116.321456, "latitude":39.987654, "altitude":120,
 "heading":135, "pitch":5, "roll":2}
```

|字段|含义|本例解读|
|---|---|---|
|uavId|无人机唯一编号|UAV001|
|uavType|机型|VTOL = 垂直起降机型|
|flightPlanId|飞行计划编号|PLAN001（关联到预先申报的飞行计划）|
|longitude / latitude|经纬度|116.32°E, 39.99°N——北京附近|
|altitude|高度（米）|120m|
|heading|航向角|135° = 朝东南飞|
|pitch / roll|俯仰 / 横滚姿态角|5° / 2°，用于推算运动趋势|

**接口 1 的输出**（系统返回的告警）：

```json
{"alarmId":"AL202608210001", "alarmType":"collision", "alarmLevel":"HIGH",
 "alarmTime":"2026-08-21 10:20:30", "uavId":"UAV001",
 "alarmDescription":"无人机存在飞行冲突风险", "suggestion":"调整航向进行避让"}
```

|字段|含义|本例解读|
|---|---|---|
|alarmId|告警编号|AL + 日期(20260821) + 当日序号(0001)|
|alarmType|告警类型|collision = 碰撞冲突类|
|alarmLevel|告警等级|HIGH 高级|
|alarmTime|告警时间|2026-08-21 10:20:30|
|alarmDescription|人读描述|"存在飞行冲突风险"|
|suggestion|初步建议|"调整航向避让"|
