    



### 架构







**整体分层架构**

```
┌─────────────────────────────────────────────────┐
│                  表现层 (UI Layer)                 │
│  左侧面板  │  顶部工具栏  │  底部时间轴  │  右侧属性  │
├─────────────────────────────────────────────────┤
│                业务逻辑层 (Service Layer)            │
│  场景管理  │  数据适配  │  状态管理  │  事件总线     │
├─────────────────────────────────────────────────┤
│              可视化引擎层 (Cesium + 封装)             │
│  Entity API  │  Primitive API  │  PostProcess    │
├─────────────────────────────────────────────────┤
│                  数据层 (Data Layer)                │
│  3D Tiles  │  GeoJSON  │  CZML  │  glTF  │  IoT实时流│
└─────────────────────────────────────────────────┘
```

---

**▎核心功能模块**

**· 1. 场景管理模块（核心大脑）**

协调所有可视化元素：

- **场景树（Scene Graph）**：管理所有 Entity / Primitive 的增删改查、显示隐藏
- **图层管理**：类似 GIS 的图层概念 —— 底图、建筑白模、倾斜摄影、点云、标注层
- **相机管理**：飞行漫游（`flyTo`）、视角切换、书签视角保存
- **时钟/时间轴**：Cesium Clock，用于时序数据回放（历史轨迹、施工进度模拟）

**· 2. UI 面板经典布局**

```
┌──────┬─────────────────────────┬──────┐
│ 左侧  │                         │ 右侧  │
│ 图层树│                         │ 属性  │
│ 设备  │      Cesium 视窗         │ 面板  │
│ 列表  │      (Viewer/Map)       │ 实时  │
│ 搜索  │                         │ 数据  │
│      │                         │      │
├──────┴─────────────────────────┴──────┤
│         底部：时间轴 / 回放控制           │
└────────────────────────────────────────┘
```

典型面板分工：

- **左侧**：图层树、设备分类树、空间查询/搜索
- **顶部**：工具栏（测量、标绘、截图、全屏、视角切换）
- **右侧**：选中对象属性面板、实时 IoT 数据卡片、告警列表
- **底部**：时间轴播放器（Cesium 原生或自定义 `Timeline` 控件）

**· 3. 数据接入层**

| 数据类型    | 格式               | 用途               |
| ------- | ---------------- | ---------------- |
| 建筑/场景底图 | 3D Tiles         | 城市白模、BIM 模型、倾斜摄影 |
| 矢量数据    | GeoJSON          | 区域边界、管线、设备点位     |
| 时序数据    | CZML             | 轨迹回放、动态目标        |
| 物联网实时   | WebSocket / MQTT | 传感器数值、设备状态       |
| 点云      | pnts (3D Tiles)  | 激光扫描             |
| 标注/覆盖物  | GeoJSON / Entity | 设备标签、告警气泡        |

**· 4. 交互与效果**

- **拾取（Picking）**：`scene.pick()` + `scene.drillPick()` 实现点击选中 → 弹出信息窗口
- **高亮/聚焦**：选中对象加外发光或变色（`CustomShader` / 回调属性）
- **飞行导航**：`camera.flyTo()` 到指定设备/区域
- **测量工具**：距离、面积、高度测量
- **标绘工具**：点、线、面、文字的临时标注
- **剖切/裁剪**：`clippingPlanes` 查看建筑内部

**· 5. 后处理效果（PostProcess）**

- Bloom（泛光）、景深、环境光遮蔽（AO）
- 天气效果（雨、雪、雾）
- 光照模拟（日照分析、阴影）

**▎典型技术组合**（不限框架，仅思路）

```
UI 框架 (Vue3 / React)     ← 管理面板、弹窗、表单
    ↕ 通信（状态管理：Pinia / Zustand）
Cesium 封装层               ← 单例 Viewer，统一 API
    ↕
CesiumJS (CDN / npm)       ← 原生能力
    ↕
后端服务（REST / WebSocket）   ← 数据接口 + 实时推送
```

关键设计模式：

- **Cesium 单例**：全局只有一个 `Viewer` 实例，UI 框架通过封装层间接操作
- **数据-视图分离**：数据层接收后端数据 → 转换为 Entity/Primitive → 渲染；反向（用户交互）同样解耦
- **事件驱动**：场景选中 → 事件总线 → UI 面板响应；IoT 数据推送 → 事件总线 → 场景更新

**· 数据流示意**

```
IoT设备 → MQTT Broker → 后端 → WebSocket → 前端
                                              ↓
                                    事件总线 → 状态管理
                                              ↓
                                    Cesium Entity 更新
                                    （颜色/位置/标签变化）
```
