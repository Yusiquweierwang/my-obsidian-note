





#### 精细度等级
GB/T 51301

|     等级      |  阶段   |             精细到什么程度             |
| :---------: | :---: | :-----------------------------: |
| **LOD 100** |  概念   |        只有大致体量(长宽高、面积、位置)        |
| **LOD 200** |  方案   |           粗略几何形状,大致尺寸           |
| **LOD 300** |  施工图  |         精确几何,构件尺寸、位置都准          |
| **LOD 350** |  深化   | 在 300 基础上,加构件之间的**连接关系**(碰撞、接口) |
| **LOD 400** | 加工/施工 |        含加工制造、安装信息,可直接下料         |
| **LOD 500** |  竣工   |     反映**实际建成**状态(as-built)      |


#### 国内标准
把模型精度分为两个东西分开定义：
+ 几何精度（G）
+ 信息深度（N）
