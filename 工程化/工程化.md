



```
vue-project/
├── index.html                 ← 唯一的 HTML，啥都不放，只有一行 <div id="app">
├── package.json               ← 记录了"依赖哪些包 + 什么命令"
├── vite.config.js             ← Vite 配置（基本不动）
└── src/
    ├── main.js                ← 入口：创建 Vue 应用，挂载到 #app
    ├── App.vue                ← 根组件：页面的骨架
    ├── router/
    │   └── index.js           ← 路由：哪个 URL 对应哪个页面
    ├── stores/
    │   └── user.js            ← Pinia：跨页面共享状态
    ├── views/
    │   ├── HomeView.vue       ← 一个"页面"
    │   └── AboutView.vue      ← 另一个"页面"
    ├── components/
    │   ├── HeaderBar.vue      ← 可复用的"积木块"
    │   └── MapPanel.vue
    └── assets/
        └── style.css          ← 全局样式

```

用户输入url到看见页面：
```
① 用户访问 http://localhost:5173
         ↓
② index.html  里有一个 <div id="app"></div>
         ↓
③ main.js  执行：
   import { createApp } from 'vue'
   import App from './App.vue'
   createApp(App).mount('#app')    ← 把 App.vue 塞进那个 div
         ↓
④ router/index.js  根据 URL 决定显示哪个页面
   /        → HomeView.vue
   /about   → AboutView.vue
         ↓
⑤ App.vue  里用 <RouterView /> 渲染当前页面的内容
         ↓
⑥ 页面组件里可以组合各种子组件
   HomeView.vue：
     <HeaderBar />      ← 来自 components/
     <MapPanel />       ← 来自 components/
     data: piniaStore    ← 来自 stores/

```


|文件|职责|类比|
|---|---|---|
|`main.js`|启动 Vue，挂载|汽车点火|
|`App.vue`|页面外壳（导航栏 + 内容区）|车身框架|
|`router/index.js`|URL → 页面的映射|GPS 导航|
|`views/`|每个"页面"|你要去的目的地|
|`components/`|可复用的 UI 积木|轮胎、方向盘|
|`stores/`|跨页面共享的数据|油箱，哪都能用|
|`package.json`|项目依赖清单|出厂配置单|


```
API 服务器
  ↓ fetch
Pinia Store（数据唯一存放地）
  ↓ 响应式自动同步
页面 A（HomeView.vue）        页面 B（AboutView.vue）
  ↓ props 传子组件              ↓ props 传子组件
HeaderBar.vue                MapPanel.vue
```

           App.vue（壳）
         ┌─────┴─────┐

         └─────┬─────┘
      ┌───────┼───────┐

  HomeView.vue    AboutView.vue

  ┌───┴───┐       ┌───┴───┐
  │       │       │       │
Header  Map    About   Footer
