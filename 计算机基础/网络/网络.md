#### pid / 地址 / 总数
![[Pasted image 20260806152944.png]]查看资源监听器，
网路中不同pid / 地址 / 发送接收 / 总数

Edge (和 Chrome 一样，都是 Chromium 内核) 使用**多进程架构**：

| 进程类型          | 作用                  |
| ------------- | ------------------- |
| **浏览器主进程**    | 管理窗口、菜单、地址栏         |
| **GPU 进程**    | 处理图形渲染              |
| **网络进程**      | 统一处理所有网络请求          |
| **每个标签页一个进程** | 隔离不同网页，一个标签页崩溃不影响其他 |
| **每个扩展一个进程**  | 隔离浏览器插件             |

所以你看到的多个 PID，每个对应不同类型或不同标签页的进程。
